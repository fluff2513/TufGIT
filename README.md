# TufGIT🔐

> Too Useful For *GIT* - v1

A simple interactive Python script that generates a .gitignore file for your project.

## 🌴 Installation

```
git clone https://github.com/Fluff2513/TufGIT
cd TufGIT
pip install -r requirements.txt
python tufgit.py
```

## 🎀 Usage

```
python tufgit.py
```

Then just answer the questions - TufGIT does the rest!
